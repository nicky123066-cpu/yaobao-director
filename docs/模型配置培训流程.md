# 幺爆导演台：模型配置、制作流程与辅助调节培训手册

适用：独立桌面版。更新时间：2026-11-22。资料用于授课与课后查阅，软件按原有菜单手动操作。

## 建议授课安排

模型分工与准备5分钟；模型配置10分钟；单镜制作10分钟；辅助调节与故障排查10分钟；问答与实操验收5分钟。

## 2. 培训完成后能独立制作一个镜头

先学会小样验收，再扩大制作数量

### 配置

- 分清文本、图片、视频用途
- 分别保存供应商密钥
- 核对参考单价与预算

### 制作

- 按步骤手动生成
- 先检查首帧，再做动态
- 配音试听后调整镜长

### 调节

- 用辅助软件修画幅与声音
- 按报错定位连接问题
- 核对原视频任务，避免重复提交

授课提示：用3分钟说明培训目标。让学员回答：哪一步使用文本模型？哪一步使用视频模型？不需要一次性启用所有模型。

## 3. 制作流程按六个环节手动推进

每一步检查结果，再进入下一步

### 01 故事台

- 保存剧本；明确角色、场景、动作和对白

### 02 资产台

- 提取并核对角色场景；准备参考图、锁定资产

### 03 分镜台

- 编译分镜；生成或导入首帧

### 04 配音台

- 逐句配音试听；按实际声音调整镜长

### 05 动态镜头

- 在分镜台手动提交视频；保留并查询原任务编号

### 06 合成导出

- 检查画面、字幕和音轨；导出并播放MP4

授课提示：现场指向各页面入口。提醒打开软件不会自动开始生成。动态镜头是分镜台中的操作，不是另一个独立导航页面。

## 4. 不同制作任务使用不同模型

看图理解、生成图片、生成视频属于不同能力

| 任务 | 当前应用选择 | 产生的结果 |
| --- | --- | --- |
| 剧本改写 | DeepSeek 等文本模型 | 选中段落的文字改写 |
| 角色、场景、首帧 | Seedream 图片模型 | 角色参考图、分镜画面 |
| 首帧变动态 | 即梦 Seedance 2.5 标准版 | 异步生成的镜头视频 |
| 对白配音 | Windows 中文语音 | 本机 WAV 音频 |
| 合成与字幕 | 本机 FFmpeg | MP4 样片与字幕文件 |

授课提示：当前应用有千问视觉理解的推荐说明，但没有独立视觉审核工作流。不要把VL或普通文本模型填入图片生成模型字段。精准口型和逐字对齐尚未接入。

## 5. 配置前准备账号、素材与测试预算

讲师用自己的样本演示，培训文件不填写真实密钥

### 账号与连接

- DeepSeek 或其他文本供应商
- 火山方舟图片和视频权限
- 有效API Key、Base URL、模型ID

### 本机环境

- Windows 与 WebView2
- 运行诊断中的中文语音
- FFmpeg 合成环境

### 测试素材

- 一小段剧本和角色参考图
- 一个4–8秒的测试镜头
- 明确的参考单价和测试预算

授课提示：培训前检查应用能启动。密钥由账号负责人在本机输入，不通过群聊分发。测试素材应为有权使用的内容。实际模型权限以供应商账号为准。

## 6. 文本连接在“连接设置”中填写

入口：模型与设置 / 连接设置

| 字段 | 示例 | 填写与验收 |
| --- | --- | --- |
| 供应商 | DeepSeek | 也可选择已有兼容接口 |
| API地址 | https://api.deepseek.com | 填写Base URL，密钥不写进地址 |
| 文本模型 | deepseek-flash | 当前应用预设，账号开放型号优先 |
| 文本协议 | Chat Completions | Responses仅在接口明确支持时选择 |
| 检测 | 保存并检测 | 目录可访问后，仍需验证实际生成权限 |

授课提示：先选择供应商，再填字段与密钥。DeepSeek文本用于剧本选区改写。当前应用预设不代表所有账户都开放该型号，若报模型不存在，使用账户控制台可用型号。官方资料入口：https://api-docs.deepseek.com/ 。

## 7. 图片连接单独配置为生图用途

入口：模型与设置 / 短剧模型与流程 / 图片生成连接

| 字段 | 示例 | 操作要点 |
| --- | --- | --- |
| 供应商 | 火山方舟 · Seedream | 独立于文本连接 |
| API地址 | https://ark.cn-beijing.volces.com/api/v3 | 核对版本路径 |
| 图片模型ID | doubao-seedream-5-0-flash-260915 | 当前预设，按账号权限填写 |
| 参考图协议 | Seedream 原生图片参考 | 保持角色参考图一致 |
| 输出尺寸 | 先用2K | 比例在项目和分镜中核对 |

授课提示：可点击应用推荐卡的“填入此用途”，然后核对字段并保存。精修备选型号在应用推荐中展示，但生成权限与价格仍以账户为准。不要把DeepSeek地址与Seedream型号混用。

## 8. 动态镜头默认即梦 Seedance 2.5 标准版

入口：模型与设置 / 短剧模型与流程 / 动态视频连接

| 字段 | 示例 | 操作要点 |
| --- | --- | --- |
| 视频API地址 | https://ark.cn-beijing.volces.com/api/v3 | 方舟异步任务通道 |
| 视频模型ID | doubao-seedance-2-5-260628 | 默认标准版或账号实际接入点 |
| 分辨率 | 先用720p | Flash备选仅480p、720p |
| 时长 | 先测试4–8秒 | 当前通道每镜4–30秒 |
| 等待与查询 | 保留原任务编号 | 超时先查状态，再决定下一步 |

授课提示：首帧模式使用自适应画幅。当前应用台词由独立配音混入，默认不生成视频原声。不能把最长等待秒数理解为生成速度承诺。

## 9. 密钥保存、设置保存和生成是三个动作

配置完成后，仍由操作者手动发起每一步生成

### 1 加密保存密钥

- 文本供应商保存自己的Key
- 方舟图片与视频可共用其Key
- 不同供应商密钥分别保留

### 2 保存设置

- 核对地址、型号和协议
- 核对参考单价与预算
- 右上角点击“保存设置”

### 3 手动试生成

- 按需开启真实模型生成并保存
- 回到自己的项目提交一个镜头
- 检查结果和费用记录

授课提示：保存密钥不会自动保存全部设置草稿。目录检测不调用付费生成，也不能证明账号拥有生图或视频权限。密钥使用Windows当前用户加密存储，换电脑后重新配置。

## 10. 预算先按一个短镜头估算

参考金额帮助控制试错，供应商账单决定实际费用

图片张数 × 图片参考价 ＋ 视频总秒数 × 视频参考价

10镜 × 每镜6秒 × 1元/秒 ＋ 10张 × 0.15元/张 = 61.50元

- 上述单价仅为教学假设，请替换为账号实际价格。
- 定妆图、重做、多版本、文本调用等可能另计。
- 入口：模型与设置 / 用途与预算。预算是本机控制，不代表账户余额。

授课提示：让学员用自己账号的报价重算一个镜头。解释分镜数、版本数量和视频时长对费用的影响。不要把本地台账与参考估算当作供应商账单。

## 11. 提示词先固定人物，再交代动作与运镜

同一角色延用参考图、服装和外观描述

### 首帧示例

- 小夏，黑色短发，灰色外套
- 雨夜办公室，窗边中景
- 冷色电影光，人物面部清晰

### 动态示例

- 小夏走到窗边，停下看向窗外
- 镜头缓慢推进，动作连续
- 保持服装、人物和场景一致

### 整理方法

- 先写主体、场景和构图
- 再写一个明确动作和运镜
- 复杂动作拆成不同镜头

授课提示：这是可手动修改的教学示例，不是新增软件按钮。把首帧提示词用于画面，把动态描述用于视频。减少一个镜头里出现多个地点与复杂动作。可用文本模型帮忙改写文字，再人工核对。

## 12. 单镜试做有明确的检查顺序

建议练习：一句对白、一张首帧、一个短动态镜头

### 01 保存剧本

- 用自己的小段剧本；核对来源版本

### 02 核对资产

- 检查人物与场景；保留可复用参考图

### 03 检查首帧

- 人物、服装、画幅正确；确认后进入视频环节

### 04 配音试听

- 对白完整，声音可听清；实际音频不超过镜长

### 05 动态验收

- 查询原任务并预览；检查动作与人物稳定性

### 06 导出播放

- 检查字幕、音轨与黑帧；通过后再扩大制作

授课提示：讲师演示时每步停下来解释验收标准。练习需单独建立自己的项目，不使用真实客户数据。真实生成是否执行由授课者自行选择，本课件不自动调用模型。

## 13. 画面问题用独立辅助软件调节

以下是配套操作建议，不是导演台新增入口

| 问题 | 辅助工具 | 调整方法 |
| --- | --- | --- |
| 竖屏变横屏、人物被裁 | 剪映等视频编辑器 | 设9:16或16:9，选择完整保留或裁切 |
| 图片尺寸、构图不合适 | Windows画图 / 图像编辑器 | 先裁切和缩放，另存副本再手动导入 |
| 人物或服装变化 | 角色参考图 + 生图模型 | 固定外观和服装，保留同一角色参考图 |
| 镜头动作过多 | 文本编辑器 + 文本模型 | 拆分动作，逐镜写清起止状态 |
| 需要精准口型 | 专业口型工具 | 另行处理并人工验收，再导入镜头视频 |

授课提示：剪映、画图和专业口型工具均是独立软件，不宣称已集成。调整原素材前保留副本。云端辅助工具可能上传素材，授课时说明所用服务和数据去向。

## 14. 声音与字幕按实际试听结果调整

辅助软件示例：剪映。导演台内置：Windows配音与FFmpeg合成

### 对白说不完

- 先试听实际配音时长
- 拆句、拆镜或适度调语速
- 超出单镜上限时分镜处理

### 音量与噪声

- 在视频编辑器调人声音量
- 压低背景音乐，避免削波
- 降噪后再次完整试听

### 字幕与口型

- 检查字幕断句、位置和可读性
- 需要精确时间时手动调字幕
- 精准口型需专业工具另行处理

授课提示：不要为了塞进镜头无限加快语速。字幕当前按镜头边界生成，没有逐字强制对齐。导出的MP4可到剪映做字幕、人声音量、背景音乐等后期，再检查最终输出。

## 15. 常见故障先查字段，再查原任务

入口：模型与设置 / 诊断与运行，以及任务中心

| 现象 | 优先检查 | 处理方法 |
| --- | --- | --- |
| 401 / 403 | 密钥、权限、余额 | 选择正确供应商，保存有效密钥并核对权限 |
| 404 / 模型不存在 | Base URL版本与模型ID | 按账号实际开放型号或接入点修改 |
| 429 / 限流 | 供应商配额与并发 | 降低并发，按服务提示等待后再核对 |
| 视频超时 / 断网 | 原视频任务编号 | 先查询供应商状态，避免重复创建 |
| 画面、声音不合适 | 参考图、提示词、实际音频 | 先调一个镜头，验收后再批量制作 |

授课提示：目录请求404并不一定代表生成接口不可用，有些兼容服务不提供/models目录。需核对接口文档并填实际型号。未知结果的付费请求先核对状态，避免因为本机超时再次创建任务。

## 16. 超时后围绕同一个视频任务核对

本机等待结束，云端任务可能仍在运行

### 01 保留编号

- 在任务中心查看；不连续新建付费任务

### 02 核对状态

- 查询供应商任务；分清排队、运行、成功和失败

### 03 按状态处理

- 成功取回结果，运行继续查询；失败确认原因后手动重做

### 04 检查结果

- 预览视频并核对费用；再决定是否进入合成

授课提示：取消本地任务不一定取消供应商运行中的任务。界面提供核对视频任务与尝试取消供应商排队的操作。应用重启后任务保持暂停，需要操作者手动核对继续。

## 17. 课堂练习以成片检查结果评分

小组练习约10分钟，讲师逐项核对

### 配置检查

- 能说清三个模型的分工
- 地址与型号属于正确供应商
- 密钥、参考单价、预算已核对

### 素材检查

- 人物与服装一致
- 画幅正确，主体清晰
- 对白完整，镜长容纳声音

### 成片检查

- 字幕能看清、音轨正常
- 无黑帧，动作衔接自然
- 能找到原任务和费用记录

授课提示：可先用本地预演练习，再由账号负责人决定是否进行真实生成。考核时问：目录检测通过是否等于视频权限通过？答案是否。超时后第一步是什么？核对原任务编号和状态。

## 18. 讲师带走课件，学员带走操作清单

资料独立保存，软件继续使用原有手动制作页面

### 授课前

- 检查账号权限和应用环境
- 准备可公开演示的测试素材
- 保留每个环节的合格样本

### 授课中

- 按模型配置、单镜制作逐段讲
- 辅助工具通过独立软件演示
- 每一步都让学员核对结果

### 授课后

- 发放配套手册与练习清单
- 按账号实际模型更新字段
- 记录问题，再安排针对性补课

授课提示：本培训资料说明当前应用能力和独立辅助软件用法。当前没有独立视觉审核、精准口型、逐字强制对齐与专业情绪配音接口。模型可用性、价格和实际效果以供应商及账号权限为准。

## 19. 资产台支持分类、参考素材和设定复用

补充演示：资产台 / 详情 / 参考素材与多视图提示词

### 分类与设定

- 角色、场景、道具等六类资产
- 编辑外观、别名、服装和设定
- 核对后锁定，减少意外改动

### 多视图参考

- 正面、侧面、背面和面部近景
- 图片、音频和视频分别保留
- 单文件24MB以内，主图可选择

### 复用与交换

- JSON导入和导出资产设定
- 查看当前资产被哪些镜头引用
- 改主图后核对受影响镜头

授课提示：演示时使用自己的资产。上传参考素材先保存在本机，后续手动生成可能按对应协议把参考图发给供应商。资产锁定保护设定，素材版本仍需人工管理。

## 20. 分镜台保留参数、版本与资产关联

补充演示：分镜台 / 版本与参数 / 关联资产

### 镜头编辑

- 核对地点、人物、动作和对白
- 编辑镜长、景别、运镜与提示词
- 查看镜头对应的剧本来源

### 版本比较

- 比较并选择当前画面版本
- 导入图片或MP4镜头素材
- 切换已保存的视频版本

### 关联与更新

- 把角色和场景关联到镜头
- 剧本或资产改动后处理提示
- 先更新受影响镜头，再合成

授课提示：四宫格比较和参数编辑由分镜页面提供。原视频音轨默认不混入本地合成。短视频素材按镜长循环或截取，最终应完整播放检查。

## 21. 漫剧改编目前完成素材整理与剧本校对

已有视频仍需配套逐集剧本，当前不自动听写或拉片

### 01 选择素材

- 选择文件夹或逐集剧本；按文件名识别集号和排序

### 02 校对正文

- 预览视频、编辑配套文字；检查场次与时间码格式

### 03 选择写入策略

- 新增章节跳过重复来源；或替换同来源章节

### 04 回到故事台

- 手动写入已校对剧本；再按原制作步骤继续

授课提示：支持与视频同名的TXT或MD剧本。视频预览与未写入校对内容仅在当前会话中，切换项目或关闭前先写入或导出。当前没有ASR、OCR、VLM自动转写，也没有视频与台词强制对齐。

## 22. 已有功能、辅助软件和待接入能力分开讲

功能清单按当前独立导演台核对，不承诺视频演示已全部复刻

| 类别 | 包括内容 | 培训方式 |
| --- | --- | --- |
| 软件已有 | 剧本、资产、分镜、配音、动态视频、合成 | 按真实菜单演示 |
| 软件已有 | 素材导入、版本选择、任务查询、预算与导出 | 附录操作清单 |
| 独立辅助软件 | 剪映画幅、字幕、音量与后期处理 | 单独打开工具教学 |
| 尚未接入 | 自动拉片、视频自动转写、精准口型、逐字对齐 | 说明边界与替代方法 |
| 待逐项核对 | 此前视频中的其他演示和细节 | 取得可读取原片后对照 |
