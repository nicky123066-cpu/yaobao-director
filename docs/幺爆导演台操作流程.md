# 幺爆导演台操作流程

适用：独立桌面版｜逐步手动制作｜更新：2026-11-22

## 1. 制作顺序

新建项目 → 保存剧本 → 提取角色与场景 → 确定参考图 → 编译分镜 → 生成首帧 → 生成配音 → 制作动态镜头 → 合成导出。

每一步由你点击执行，完成后不会自动启动下一阶段。也可以使用静帧画面配音，跳过动态视频步骤。

## 2. 首次使用：设置模型

打开左侧“模型与设置”，分别设置文本、图片、视频用途。

|用途|推荐模型|模型ID|在哪里设置|
|---|---|---|---|
|剧本选区改写|DeepSeek Flash|`deepseek-flash`|连接设置 → 文本连接|
|人物定妆、场景、分镜首帧|Seedream 5.0 Flash|`doubao-seedream-5-0-flash-260915`|短剧模型与流程 → 图片生成连接|
|图片精修备选|Seedream 5.5|`doubao-seedream-5-5-261028`|同一图片生成连接，按需手动切换|
|动态镜头（默认）|即梦 Seedance 2.5标准版|`doubao-seedance-2-5-260628`|短剧模型与流程 → 动态视频连接|
|配音|Windows本地中文音色|选择本机已安装的音色|配音台|
|字幕与合成|本地FFmpeg|内置工具|合成导出|

文本API地址：`https://api.deepseek.com`。

图片、视频API地址：`https://ark.cn-beijing.volces.com/api/v3`。图片与视频可使用同一账户的方舟密钥。

设置顺序：

1. 填写或选定对应模型，点击“保存设置”。
2. 在软件内加密保存供应商API Key，密钥无需发到聊天里。
3. 到“用途与预算”核对图片单价、视频每秒参考估价及总预算。
4. 需要云端生成时，手动启用真实生成。本地预演可以保持关闭。

保存设置或打开应用不会自动生成。模型权限与实际费用以供应商账户为准。

## 3. 新建项目，保存剧本

**进入：项目总览 → 新建项目。**

1. 填写项目名称、梗概、集数、画幅和视觉风格。
2. 初次制作建议先做1集；手机竖屏选9:16，横屏选16:9。
3. 进入“故事台”，编写或粘贴剧本，点击“保存剧本”。
4. 需要改写时，先选中一段正文，再手动使用选区改写功能；确认后保存。

可按以下格式组织剧本，替换方括号中的内容：

```text
第1集
1-1 日 内 [场景名称]
人物：角色A
△ [人物动作和场景变化]
[00:04] 角色A（自然）：[台词内容]
```

场次、人物、动作和对白应分行。对白建议写明情绪或时间码，便于识别为台词。

**完成条件：** 剧本已保存，出场人物、场景、动作和台词清楚。当前支持选区改写，整段剧本可先在常用模型对话工具中整理后粘贴。

## 4. 提取角色与场景，确定参考图

**进入：故事台 → 提取角色与场景 → 资产台。**

1. 点击“提取角色与场景”。这一步使用本地规则，不调用付费模型。
2. 在资产台检查名称、外观、服装、场景和道具设定，补齐必要信息。
3. 上传已有参考图片，或选中资产后手动生成定妆图。
4. 对比版本，选择本次制作使用的主参考图。

**匹配模型：** Seedream 5.0 Flash；需要时手动切换Seedream 5.5。

**完成条件：** 人物和场景的设定已确认，主参考图已选定。后续镜头尽量复用同一套角色、服装和场景参考。

## 5. 编译分镜，生成首帧

**进入：分镜台。**

1. 点击“编译分镜”，检查当前章节的镜头列表。
2. 逐镜检查人物、动作、对白、景别、运镜和时长。
3. 确认镜头关联了正确资产，需要时修改补充提示词。
4. 选中镜头，点击生成或更新画面。
5. 对比画面版本，选定当前首帧。不满意的镜头单独修改并重做。

**匹配工具：** 分镜编译使用本地规则；首帧生成使用Seedream。

**完成条件：** 镜头内容正确，首帧已选定。动态视频首帧需要PNG、JPEG或WebP；本地SVG示意图不能直接用于云端动态视频。

剧本修改后，先保存并重新编译分镜，再检查受影响的画面和素材引用。

## 6. 生成配音，确定镜长

**进入：配音台。**

1. 为角色选择本机已安装的中文音色。
2. 选择台词并点击生成配音。
3. 逐句试听，检查读音、停顿和语速。
4. 台词超过镜长时，手动延长镜头或拆分台词。

**匹配工具：** Windows本地语音引擎。

**完成条件：** 每句台词均有完整配音，镜头时长能容纳语音。建议在生成动态视频前确定镜长。

## 7. 制作动态镜头

**进入：分镜台 → 对应镜头 → 生成动态镜头。**

1. 确认首帧、动作提示、运镜和最终镜长。
2. 点击“生成动态镜头”，确认本次调用后提交。
3. 到“任务中心”查看进度，等待结果下载到本地。
4. 播放镜头视频，检查人物、动作和场景。不满意时，修改当前镜头后再手动重做。

**默认模型：** 即梦 Seedance 2.5标准版，默认720p，原生异步视频任务接口。

建议先做4–6秒短镜头。当前2.5通道单镜支持4–30秒，过长内容先拆镜。也可导入已有MP4作为镜头素材。

当前使用独立配音混入成片，人物精准口型功能尚未接入。单镜生成完成后，不会自动启动其他制作阶段。

## 8. 合成并下载成片

**进入：合成导出。**

1. 查看导出前检查项，补齐缺少的画面、视频或配音。
2. 处理剧本版本变化、资产变化和台词超时提示。
3. 点击“合成MP4样片”。
4. 完成后播放整片，检查画面、字幕、音量、镜头衔接和时长。
5. 下载MP4、SRT字幕和质检报告；需要时导出当前项目素材包。

**匹配工具：** 本地FFmpeg。

系统会检查黑帧、输出时长和音轨；内容准确性、人物一致性和字幕效果仍需人工审看。字幕按镜头边界生成，尚未逐字强制对齐。当前合成使用角色配音，不混入镜头视频原声。

## 9. 任务异常时怎么处理

|情况|操作|
|---|---|
|模型或密钥未配置|返回“模型与设置”，核对用途、地址、模型ID和对应密钥|
|找不到模型、没有权限|核对供应商账户实际开放的模型或接入点|
|视频断网或超时|先在任务中心核对原供应商任务编号，再手动继续查询|
|提交结果未知|先核对供应商后台记录，避免重复创建同一镜头|
|任务暂停|核对当前步骤和已完成产物后，再手动恢复|
|画面或资产版本变化|更新受影响镜头，选定当前版本后重新合成|
|配音失败|改选本机已安装的音色，检查台词后重新生成|

退出应用后，本机未完成任务保持暂停。已提交的云端视频可能继续生成和计费，下次打开后先手动核对。

## 10. 成片前检查

- [ ] 剧本和资产设定已保存。
- [ ] 人物、服装和场景参考一致。
- [ ] 每镜画面或视频已选定。
- [ ] 配音已试听，台词没有被截断。
- [ ] 镜长、字幕、音量和整体节奏已检查。
- [ ] MP4、字幕和需要保留的项目素材已下载。

程序入口：桌面“幺爆导演台”。项目与素材保存在程序旁的`data`文件夹，建议定期备份整个文件夹。
